# Code of conduct

Treat people with respect. Discuss the behavior of the code and the evidence for a claim. Do not harass, discriminate, threaten, or expose personal information.

Keep reports useful. Use synthetic data and remove identifying details. Respect an owner's refusal to share their configuration.

Maintainers may edit or remove harmful content and restrict participation. For a private concern, request a private maintainer contact without posting personal details. Maintainers should explain the action and apply the same standard to everyone.
